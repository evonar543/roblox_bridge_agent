# RBA Autoexec Manager 1.0.1

Standalone Windows x64 GUI for enabling, updating, checking, and safely disabling
the repository's `lua/rba_autoloader.lua` in Volt, Potassium, or a custom
`autoexec` folder.

## Verify before running

- **SHA-256:** `e701ee0cc779a7786d7a1d75e59753c9fe831ba4823104fafb97e9fcdc953208`
- **VirusTotal:** [report for this exact SHA-256](https://www.virustotal.com/gui/file/e701ee0cc779a7786d7a1d75e59753c9fe831ba4823104fafb97e9fcdc953208/detection)
- **Source:** the `rba-autoexec-manager-v1.0.1` tag in this repository
- **Windows signature:** unsigned; an unknown-publisher warning is expected

Run this after downloading:

```powershell
Get-FileHash -Algorithm SHA256 ".\RBA.Autoexec.Manager.exe"
```

The output must exactly match the SHA-256 above. A matching checksum verifies
file identity. VirusTotal and antivirus results are useful additional signals,
but no scanner result guarantees that software is safe.

## Safety behavior

- Embeds the loader directly from this repository.
- Rejects a drive root as an autoexec destination.
- Creates a timestamped backup before replacing a different loader.
- Disables by moving the active loader to a recoverable sidecar.
- Stores only its selected-target setting under Local AppData.

Validated with the repository test suite, .NET formatting checks, a Release
single-file publish, the built-in loader lifecycle/GUI construction self-test,
and a live Windows main-window startup check.
