# Changelog

All notable changes to Roblox Bridge Agent are documented here.

## 1.0.0 - 2026-08-01

- Published the project as Roblox Bridge Agent (`RBA`) with a fresh repository identity.
- Added shared websocket discovery, proxy attachment, connection-state publishing, and bounded protocol-v4 execution.
- Added Script Capsules with explicit permissions, preflight checks, source snapshots, rollback, and guarded execution.
- Upgraded the local dashboard into an animated Script OS command center with live status and capsule controls.
- Added crash detection, verified Roblox restart, development snapshots, screenshots, event logging, and performance safeguards.
- Added profiles, autorun, file watching, source backup/restore, autoexec synchronization, and explicit Git sync helpers.
- Added project branding, CI, packaging allowlists, security guidance, architecture documentation, and release tests.
