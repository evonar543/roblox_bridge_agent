# RBA Autoexec Manager 1.0.2

This release fixes complete-disable behavior. Executors may inspect every file in
an `autoexec` folder regardless of a backup-like extension, so disabled and
backup copies no longer remain there.

## What changed

- Disable moves every RBA-managed loader, backup, old disabled copy, and orphan
  temporary file out of `autoexec`.
- Recoverable files are stored under Local AppData in
  `RBA Autoexec Manager\loader-storage`.
- Enable restores a matching disabled loader from safe storage when possible.
- While enabled, only the active `rba_autoloader.lua` remains in `autoexec`.
- Status detects unsafe legacy sidecars and offers cleanup.

## Verify before running

- **SHA-256:** `59ed541ba09851c876c8091f84810712359229a1b6475aa82ab32677240cdb3b`
- **Source:** the `rba-autoexec-manager-v1.0.2` tag in this repository
- **Windows signature:** unsigned; an unknown-publisher warning is expected

```powershell
Get-FileHash -Algorithm SHA256 ".\RBA.Autoexec.Manager.exe"
```

The output must exactly match the SHA-256 above. No VirusTotal link from an
earlier build applies to this file because every changed EXE has a different
hash. Scanner results are useful signals, not guarantees of safety.
